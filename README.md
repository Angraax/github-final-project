# github-final-project

## Simple Interest Calculator

This project provides a Bash script that calculates simple interest from a
principal amount, an annual rate of interest, and a time period in years.

The calculation used is:

```text
simple interest = principal * rate * time / 100
```

## Usage

Run the script and enter the requested values:

```bash
bash simple-interest.sh
```

The script displays the calculated simple interest.
